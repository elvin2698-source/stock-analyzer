# 주식 추천 분석 프로그램

한국(코스피·코스닥)과 미국(나스닥·뉴욕·아멕스)의 **전 상장 종목**을 매일 분석해서
**추천 / 중립 / 비추천** 등급과 판단 근거를 보여줍니다.

> ⚠️ 정해진 규칙에 따라 점수를 매긴 참고 자료이며, 투자 권유나 수익 보장이 아닙니다.

## 결과 보는 곳
**웹 대시보드(매일 자동 갱신)**: https://elvin2698-source.github.io/stock-analyzer/
휴대폰에서는 브라우저 메뉴의 '홈 화면에 추가'로 앱처럼 쓸 수 있습니다.

| 파일 | 내용 |

| `results/추천결과_날짜.xlsx` | 엑셀 (요약 / 업종별 요약 / 추천 / 비추천 / 전체_한국 / 전체_미국 / 설명), 열마다 필터 버튼 |

## 점수 계산 방법 (100점 만점)
**기술적 분석 50점**
- 추세 20: 현재가 > 200일선, 20일선 > 60일선, 현재가 > 20일선
- 모멘텀 15: 최근 3개월 수익률 순위
- RSI 10: 40~60 안정 / 70 초과 과열 감점 / 30 미만 과매도
- 거래량 5: 거래량 급증과 함께 오르면 가점, 내리면 감점

**가치 분석 50점** (같은 업종끼리 비교)
- PER 15 (낮을수록) · PBR 10 (낮을수록) · ROE 15 (높을수록) · 배당 5 (높을수록)

## 분류
- **업종 대분류**: 한국(KSIC 160여 개)·미국(Nasdaq 150여 개) 업종을 23개 공통 분류로 묶음 (`src/categorize.py`)
- **규모**: 한국은 시가총액 1~100위 대형주, 101~300위 중형주, 나머지 소형주 / 미국은 100억$ 이상 대형주, 20억$ 이상 중형주
- **스타일**: 저평가, 고수익성, 고배당, 상승추세, 하락추세, 모멘텀 강세, 과매도, 과열, 적자

**70점 이상 추천, 40점 이하 비추천**, 그 사이는 중립.
거래대금이 너무 적거나 상장 60거래일 미만인 종목은 제외합니다.
기준은 `src/config.py`에서 바꿀 수 있습니다.

## 모의투자 (규칙 v2, `src/paper.py`)
시장마다 전략 계좌 5개(각 5천만원)를 동시에 운영해서 서로, 그리고 시장 지수와 비교합니다.
균형형 · 안정형(대·중형주) · 공격형 · 균형형+하락장 방어 · **무작위 대조군**(실력과 운을 가르는 비교용)

- **체결**: 신호 다음 거래일 시가, 0.1% 불리하게 / 수수료·거래세·환전 수수료·배당세 반영
- **현실성**: 한국 상·하한가 체결 제한, 매수 금액은 20일 평균 거래대금의 1%까지
- **기업 이벤트**: 액면분할 자동 보정, 배당 현금 입금
- **비교 기준**: 코스피·코스닥 / S&P500·S&P500 배당포함·러셀2000 + 분석 대상 전 종목 동일가중 지수
- **성과 지표**: 수익률, 최대 낙폭, 변동성, 샤프, 베타, 승률, 평균 보유일, 회전율
- **기록**: `paper/` (보유·주문·매매·날짜별 평가, 주간 리포트 `paper/reports/`, 규칙 기록 `paper/RULES.md`)

## 점수 검증 (`src/validate.py`)
- 매일 전 종목 점수를 `paper/signals/`에 남기고, 1주·1개월·3개월 뒤 실제 수익률과 비교 (IC, 5분위, 등급별)
- 과거 2년 주가로 기술점수 백테스트 (상위 20종목 매주 교체 vs 동일가중)

## 자동 검사
- `tests/`: 모의투자 체결·비용·배당·액면분할·상한가·거래대금 한도·현금 회계, 점수 검증 계산
- 코드가 바뀌면 GitHub에서 자동으로 검사하고, 매일 분석 전에도 검사합니다. 분석이 실패하면 저장소에 알림 이슈가 생깁니다.

## 데이터 출처
- 한국: 종목 목록·PER·PBR·배당은 네이버 증권, 업종은 KRX 상장공시시스템(KIND), 주가는 Yahoo Finance (로그인 필요 없음)
- 미국: 종목 목록은 Nasdaq 스크리너, 주가와 재무지표는 Yahoo Finance (`yfinance`)
- 미국 재무지표는 종목마다 따로 받아야 해서, 하루 1,500종목씩 돌아가며 갱신합니다 (약 4~5일이면 전체 갱신)

## 매일 자동 실행 (GitHub Actions)
`.github/workflows/daily.yml`이 평일 하루 두 번 실행됩니다.
- 한국시간 17:43 (한국장 마감 후)
- 한국시간 07:13 (미국장 마감 후)

따로 설정할 것은 없습니다. **Actions** 탭 → **매일 주식 분석** → **Run workflow**로 바로 실행할 수도 있습니다.

## 직접 실행
```bash
pip install -r requirements.txt
python src/main.py              # 한국 + 미국
python src/main.py --only KR    # 한국만
python src/main.py --no-collect # 이미 받은 데이터로 분석만
```
처음 실행할 때는 1년치 주가를 받느라 오래 걸립니다 (한국·미국 합쳐 약 20~40분).
이후에는 새로 생긴 날짜만 받습니다.
