# 주식 추천 분석 프로그램

한국(코스피·코스닥)과 미국(나스닥·뉴욕·아멕스)의 **전 상장 종목**을 매일 분석해서
**추천 / 중립 / 비추천** 등급과 판단 근거를 보여줍니다.

> ⚠️ 정해진 규칙에 따라 점수를 매긴 참고 자료이며, 투자 권유나 수익 보장이 아닙니다.

## 결과 보는 곳
| 파일 | 내용 |
|---|---|
| `docs/index.html` | 웹 대시보드 (검색, 필터, 정렬, 판단 근거) |
| `results/추천결과_날짜.xlsx` | 엑셀 (요약 / 추천 / 비추천 / 전체_한국 / 전체_미국 / 설명) |
| `results/추천결과_날짜.csv` | 같은 내용의 CSV |
| `data/companies_kr.csv`, `data/companies_us.csv` | 기업 정보 (업종, 시가총액, PER, PBR, ROE, 배당) |

## 점수 계산 방법 (100점 만점)
**기술적 분석 50점**
- 추세 20: 현재가 > 200일선, 20일선 > 60일선, 현재가 > 20일선
- 모멘텀 15: 최근 3개월 수익률 순위
- RSI 10: 40~60 안정 / 70 초과 과열 감점 / 30 미만 과매도
- 거래량 5: 거래량 급증과 함께 오르면 가점, 내리면 감점

**가치 분석 50점** (같은 업종끼리 비교)
- PER 15 (낮을수록) · PBR 10 (낮을수록) · ROE 15 (높을수록) · 배당 5 (높을수록)

**70점 이상 추천, 40점 이하 비추천**, 그 사이는 중립.
거래대금이 너무 적거나 상장 60거래일 미만인 종목은 제외합니다.
기준은 `src/config.py`에서 바꿀 수 있습니다.

## 데이터 출처
- 한국: 종목 목록·PER·ROE는 네이버 금융, 업종은 KRX 상장공시시스템(KIND), 주가는 Yahoo Finance
  (로그인 필요 없음. PBR은 PER × ROE로 계산, 배당 정보는 없어서 중립 처리)
- 미국: 종목 목록은 Nasdaq 스크리너, 주가와 재무지표는 Yahoo Finance (`yfinance`)
- 미국 재무지표는 종목마다 따로 받아야 해서, 하루 1,500종목씩 돌아가며 갱신합니다 (약 4~5일이면 전체 갱신)

## 매일 자동 실행 (GitHub Actions)
`.github/workflows/daily.yml`이 평일 하루 두 번 실행됩니다.
- 한국시간 17:43 (한국장 마감 후)
- 한국시간 07:13 (미국장 마감 후)

따로 설정할 것은 없습니다. **Actions** 탭 → **매일 주식 분석** → **Run workflow**로 바로 실행할 수도 있습니다.

## 직접 실행
```bash
pip install -r requirements.txt
python src/main.py              # 한국 + 미국
python src/main.py --only KR    # 한국만
python src/main.py --no-collect # 이미 받은 데이터로 분석만
```
처음 실행할 때는 1년치 주가를 받느라 오래 걸립니다 (한국·미국 합쳐 약 20~40분).
이후에는 새로 생긴 날짜만 받습니다.
